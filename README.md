## Документация для кода OSM Parser

### Общее описание
Этот скрипт предназначен для определения типа зданий по их адресам, используя геокодирование и API Overpass для получения данных об объектах. Скрипт считывает данные из CSV-файла, обрабатывает каждую строку, определяет тип здания и сохраняет результаты обратно в DataFrame.

### Импортируемые библиотеки
- `geopy.geocoders`: Используется для геокодирования адресов.
- `requests`: Библиотека для выполнения HTTP-запросов.
- `pandas`: Используется для работы с данными в формате таблицы (DataFrame).
- `tqdm.notebook`: Используется для отображения индикатора прогресса в Jupyter-ноутбуках.
- `time`: Библиотека для работы со временем (в данном случае используется для задержки между запросами).

### Переменные
#### `building_type_translation`
Словарь для перевода типов зданий с английского на русский. Содержит пары «ключ-значение», где ключ — это тип здания (на английском), а значение — его перевод (на русском).

### Функция `get_building_type(address)`
```python
def get_building_type(address):
```
#### Параметры
- `address` (str): Адрес здания, тип здания которого будет определен.

#### Возвращаемое значение
- (str): Тип здания (переведенный и оригинальный), или "unknown", если тип не удалось определить.

#### Описание работы
1. **Геокодирование**: Адрес передается в `Nominatim` для получения координат (широта и долгота).
2. **Запрос к Overpass API**: Формируется запрос для поиска зданий, находящихся в радиусе 50 метров от полученных координат.
3. **Обработка ответа**:
   - Если нет найденных объектов, возвращает "unknown".
   - Если объекты найдены, извлекается тип первого здания из ответа.
4. **Обработка исключений**: Все ошибки обрабатываются с выводом сообщения и возвратом "unknown".

### Примечания
- Убедитесь, что в CSV-файле правильно указаны адреса.
- Учитывайте, что функции API могут иметь ограничения на количество запросов, поэтому рекомендуется использовать задержку между ними.
- Перевод типов зданий обеспечивается через словарь `building_type_translation`, но в текущей версии кода этот функционал не используется. Можете добавлять логику, чтобы возвращать перевод из этого словаря.
